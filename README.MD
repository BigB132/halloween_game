Exported from scratch using turbowarp packager.  
For more details and to play the game go on [scratch](https://scratch.mit.edu/projects/1395803399/).

The goal of the game is to save Professor E. Gadd from the ghosts (which apparently are attacking him). Luigi (aka the player) has a flashlight and a vacuum which he can use to kill ghosts. He has to go through many rooms and has to kill many ghosts to save Professor E. Gadd.

I am pretty happy on how the game turned out, but even though there are some bugs and imperfections  it is really fun to play.
